# リリース履歴

利用者へ公開したバージョンと変更内容を記録する。Commit単位の細かい履歴は [[2026-07]]など`04_開発ログ`を参照。採番ルールは[[開発ルール]]の 「バージョン管理」を参照。

## v1.0.16（2026-09-08）

- コーピングの時間・場所タグ（[[ISS-034]]）：状態カテゴリとは別に「時間」（すぐできる／少し時間がかかる）「場所」（どこにいてもできる／誰もいないところでする／道具や設備があるところ）のタグをプリセット49件に付与。一覧の「並び替え」ボタンから基本／時間順／場所順を切り替えられるようにし、時間順・場所順選択時はグループ見出しで一覧を再構成。マイコーピングにも同フィールドを任意入力で追加

## v1.0.15（2026-09-07）

- コーピング処方箋の追加修正（[[ISS-031]] v15 / [[ISS-032]] v2）：マイコーピングの新規追加・編集フォームで、スマホ実機を開くと自動ズームインしてしまう不具合を修正（入力欄フォントサイズを16px以上に変更）。コーピング詳細の「効果のイメージ」が「詳細」より視覚的に目立ちすぎていたバランスを調整（詳細のフォントサイズ・文字色を強化、効果のイメージは枠・文字色を維持しつつフォントサイズを縮小）

## v1.0.14（2026-09-07）

- コーピング処方箋の公開後修正（[[ISS-031]] v14 / [[ISS-033]] v2〜v4）：詳細・効果のイメージの表示順を修正。ボタンアイコン・名称を統一（「自分用に変えて追加」→「編集して追加」）。プリセットの重複登録を防止（`sourcePresetId`による紐付け、そのまま追加は厳密ブロック・編集して追加は確認ダイアログ）。「駅長のヒント集」に登録済みバッジを追加

## v1.0.13（2026-09-03）

- プリセットをマイコーピングへ追加（[[ISS-033]]）：処方箋・プリセット一覧のコーピングに「そのまま追加」「自分用に変えて追加」の2つのボタンを実装。プリセット内容を初期値に新しいマイコーピングを作成できるようにした（元のプリセットは変更されない）。あわせて[[ISS-032]]（登録UX改善）も、本ISSとISS-031の実装により完了条件を満たしたため公開済みへ

## v1.0.12（2026-09-03）

- コーピング処方箋の全面再設計（[[ISS-031]]）：状態選択のみだったUIを、状態タブ（5カテゴリ）＋フィルタ＋アコーディオン一覧のドリルダウン型に再設計。ランダム抽選（3件表示）を撤廃し全件表示に変更。マイコーピングの登録・編集・削除・使用ログ記録を統合。コーピングデータをNotebookLM由来の素材で拡充（15件→49件）し、全件のタイトル・詳細文体を統一。「効果のイメージ」フィールドを新設

## v1.0.11（2026-08-17）

- 瞑想完了後の不要な確認ダイアログを削除（[[ISS-045]]）：完了画面で×を押した際、`requestBreathingExit()`の条件漏れにより不要な「終了しますか？」確認ダイアログが表示されていた問題を修正。完了画面表示中は確認なしで直接閉じるように変更

## v1.0.10（2026-08-17）

- BGM音量のバランス調整（[[ISS-046]]）：環境音（洞窟・せせらぎ・焚火・水琴窟）のゲイン値が、開始音・終了のシンギングボウルに対して極端に小さかった問題を修正。`AMBIENCE_VOLUMES`の各値を約6倍に引き上げ

## v1.0.9（2026-08-17）

- 呼吸パターンのカスタマイズ（[[ISS-041]]）：マインドフルネス瞑想の呼吸法を、4・7・8呼吸固定から腹式呼吸（デフォルト）・4・7・8呼吸法・ボックスブリージング・数息観の4種から選択できる形に改修。呼吸法選択の開閉式メニュー、各呼吸法の詳しい解説（効果／方法／コツ）、ⓘアイコンからの基本姿勢パネルを追加。ボックスブリージングは正方形ガイド、数息観はタップ駆動のカウント表示に対応

## v1.0.8（2026-08-09）

- 発車標エリアのアイコンループ・光の縁取り演出（[[ISS-044]]）：発車標 テキストを「マインドフルネス瞑想」に統一。時計→リンゴ→駅長ペンギンの アイコンをフェードでループ表示。ピンクの枠がbox-shadowで呼吸するよう に発光する演出を追加

## v1.0.7（2026-08-08）

- 銀河鉄道のグラフィック刷新（[[ISS-025]]）：夜空表示範囲の拡大（線路が 見えるように）、列車アニメーションを白い線画デザインに刷新、夜空を 斜め上方向へ飛行し月と重なる演出、軌跡パーティクル効果を追加

## v1.0.6（2026-08-06）

- 呼吸法フィールドのモーダル化（[[ISS-027]]）：ホーム画面から独立した モーダルに変更。発車標のテキストクリックで起動。リンゴ （`fa-apple-whole`）＋フェーズ別ガイドリング、セッション時間選択、 一時停止／再生・リセット操作、テーマ切替（白／黒）に対応

## v1.0.5（2026-07-31）

- 呼吸法・環境音の音質向上（[[ISS-028]]）：合成音からファイル再生方式へ変更。 海→洞窟、雨→水琴窟に差し替え。シンギングボウルも音源ファイル化
- またたく星々の再開（[[ISS-030]]）：station_scene.png統合前のアニメーションを移植
