# リリース履歴

## v1.0.8（2026-08-09）

- 発車標エリアのアイコンループ・光の縁取り演出（[[ISS-044]]）：発車標 テキストを「マインドフルネス瞑想」に統一。時計→リンゴ→駅長ペンギンの アイコンをフェードでループ表示。ピンクの枠がbox-shadowで呼吸するよう に発光する演出を追加

## v1.0.7（2026-08-08）

- 銀河鉄道のグラフィック刷新（[[ISS-025]]）：夜空表示範囲の拡大（線路が 見えるように）、列車アニメーションを白い線画デザインに刷新、夜空を 斜め上方向へ飛行し月と重なる演出、軌跡パーティクル効果を追加

## v1.0.6（2026-08-06）

- 呼吸法フィールドのモーダル化（[[ISS-027]]）：ホーム画面から独立した モーダルに変更。発車標のテキストクリックで起動。リンゴ （`fa-apple-whole`）＋フェーズ別ガイドリング、セッション時間選択、 一時停止／再生・リセット操作、テーマ切替（白／黒）に対応

## v1.0.5（2026-07-31）

- 呼吸法・環境音の音質向上（[[ISS-028]]）：合成音からファイル再生方式へ変更。 海→洞窟、雨→水琴窟に差し替え。シンギングボウルも音源ファイル化
- またたく星々の再開（[[ISS-030]]）：station_scene.png統合前のアニメーションを移植
