# リリース履歴

利用者へ公開したバージョンと変更内容を記録する。Commit単位の細かい履歴は [[2026-07]]など`04_開発ログ`を参照。採番ルールは[[開発ルール]]の 「バージョン管理」を参照。

## お知らせ文の扱い

各エントリの本文は開発向けの記録、**お知らせ文**は利用者向けの文章で、役割が
異なる。前者から後者は作れないため、両方をここに並べて置く。

- **このページがお知らせ文の正本。** `index.html`の`APP_NEWS`は、ここからの写し
- 採番したら、開発向けの記録とお知らせ文の両方を書く。片方だけの状態を作らない
- 採番しない変更（デプロイ設定の修正など）はお知らせ文も不要
- 1件のお知らせ文が複数バージョンをまとめることがある。その場合は最初の
  バージョンに書き、どこまでを案内しているかを明記する
- 項目は「日付／カテゴリ／タイトル／本文／注意書き／アプリ掲載」。カテゴリは
  `不具合解消` / `機能追加` / `改善` の3種。注意書きは任意
- **採番したものすべてをアプリへ載せるわけではない。** 判断基準は「利用者が
  メイン機能で体感する変更かどうか」。載せないものは**アプリ掲載：なし**と書く。
  文章自体はこのページに残す（[[ISS-063]]）
- **本文の1行目は、アプリ側で折りたたんだときに見える唯一の行になる**（[[ISS-063]]）。
  一番大事なことを1行目に書く
- `APP_NEWS`への反映は、そのリリースをCodexへ実装依頼するときに同じ依頼へ含める。
  文章はその前にチャットで確定させ、まずこのページへ書く
