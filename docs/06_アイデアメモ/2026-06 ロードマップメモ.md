
# 2026-06 ロードマップメモ

## メモ

- 「みんなの途中下車」は、既存の[[ISS-016]]（途中下車ポスト＝投稿窓口）・ [[ISS-017]]（駅長ピックアップ＝駅長による選定）とセットになる、閲覧用の 掲示板機能と位置づけられる。この3つが揃って初めてPhase3構想が形になる
- 「支援者共有」は、[[ISS-019]]（レポート出力）の共有先を広げる構想として 関連づけられる。ただしプライバシー・セキュリティ面の検討が別途必要
- 大きなロードマップとしてはまだ確定していないが、忘れないよう`次の停車駅` Excelに検討中／保留として起票済み（ISS-035〜039）
