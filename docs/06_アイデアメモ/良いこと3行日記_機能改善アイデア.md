
# 良いこと3行日記 ─ 毎日使ってもらうための機能改善アイデア

このノートは「アイデアメモ」です。ISS化はまだ確定していません。 思いついたアイデアを蓄積し、育ってきたものから[[ISS一覧]]へ切り出します。

## 背景

良いこと3行日記を毎日使ってもらうための改善案。テーマ別に4つの切り口で整理。

## 見返しやすさ

- カレンダー表示や「駅の路線図」のようなビジュアルで、書いた日が積み重なって いく様子が一目で分かる
- ランダムに過去の1件が「今日の思い出」的に浮かび上がる仕組み （去年の今日、1ヶ月前の今日、など）
- キーワードや感情タグで絞り込んで振り返れると、「自分にとって良いことの パターン」が見えてくる

## 入れたときの反応

- 駅長ペンギンが一言リアクションをくれる（「いい発見だね」「今日もお疲れさま」）
- 書き終わった瞬間に何か小さな演出（切符が発券される、駅のランプが灯る、 みたいな世界観に沿った動き）
- 連続記録日数がさりげなく見える（プレッシャーにならない程度に）

## 入れたくなる導線

- 通知は「書いてください」より「今日、駅長が待ってるよ」くらいの柔らかさで
- ホーム画面を開いた瞬間に日記への入り口が自然に目に入る配置
- 他の機能（コーピングやセルフトーク）を使った後に「今日の良かったことも 書いてみる？」と軽く誘導

## 効果の可視化

- 週や月単位で「良いことログ」が積み上がっていくグラフや、駅の乗車距離みたいな メタファー
- 書き続けた人の変化（例えば感情タグの推移）をさりげなく見せる
- 「なぜ効果があるのか」を短い説明で添える（スリーグッドシングスの理屈を 駅長の言葉で伝える）
