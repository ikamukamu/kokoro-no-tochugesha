
# マインドフルネス瞑想 ─ 駅長ペンギンによる図解イラストのアイデア

このノートは「アイデアメモ」です。ISS化はまだ確定していません。
思いついたアイデアを蓄積し、育ってきたものから[[ISS一覧]]へ切り出します。

## 背景

[[ISS-041]]（呼吸パターンのカスタマイズ）のレビュー中に、ⓘ「基本の姿勢」パネルへ駅長ペンギンの図解イラストを添えたい、というアイデアが挙がった。

## アイデアの内容

- ⓘ「基本の姿勢」パネルの姿勢説明（背筋を伸ばし〜など）に、駅長ペンギンが実際にその姿勢を取っているイラストを添える
- 各呼吸法の説明（効果／方法／コツ）にも、同様の図解イラストがあるとさらに分かりやすい・親しみやすくなりそう

## 実装タイミングの想定

- 今回のISS-041改修では実装しない（スコープ外）
- 駅長ペンギンのイラスト素材をまとめて用意する必要があるため、[[ISS-042]]（完了後のスタンプ演出）と同じタイミングでの検討が有力候補。スタンプ演出でも駅長ペンギンの新規イラスト素材が必要になるはずなので、まとめて素材を作る方が効率的
