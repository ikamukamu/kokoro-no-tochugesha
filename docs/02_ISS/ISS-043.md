# ISS-043 星の瞬きがプラットフォーム・駅舎でも表示される不具合

## 概要

[[ISS-030]]（またたく星々の再開）の実装後、星の瞬きが`station_scene.png` （プラットフォーム・駅舎・夜空が1枚に描かれた画像）全体に表示されてしまい、 本来星が表示されるべきでないプラットフォームや駅舎の中にまで星が明滅する 状態になっている。

**注意：** 夜空の中で「絵に描かれた星」と「動く星」が重なること自体は 問題ではない（むしろ賑やかで良い）。問題は、プラットフォームや駅舎の中に まで星が表示されてしまうこと。

## 背景

[[ISS-030]]の完了報告時点では、ローカルサーバー経由での動作確認で問題は 見られなかったが、実際の利用の中で発覚した。

### 原因（判明済み）

`index.html`を調査した結果、以下が判明した。

- `#starry-sky-bg`（[[ISS-030]]で復活させた、プログラムで動く星）は、 `<header class="nr-home-header">`直下に配置されており、`position: absolute; inset: 0;`でヘッダー全体に星をばら撒く実装になっている
- `station_scene.png`（プラットフォーム・駅舎・夜空が1枚に描かれた画像）は ヘッダーの中の一部領域（`#nr-station-home-scene`）に表示されている
- 結果として、星がヘッダー全体（駅舎・プラットフォーム部分も含む）に ばら撒かれてしまっている

### 一度試みて撤回した対応

1. `#starry-sky-bg`の表示範囲を`#nr-station-home-scene`（絵全体）に限定する 修正をCodexに実装してもらったが、これは「絵全体」に限定しただけで、 絵の中の「駅舎・プラットフォーム部分」にも星が表示される問題は解決 しなかった
2. `station_scene.png`から星を画像編集で除去する対応も試みたが、文字が つぶれる等の品質劣化があり、また「夜空の中の二重表示は問題ない」という 方針とも合わないため撤回した。**画像編集は行わず、元の画像をそのまま 使う方針に確定。**

## 目的

- 星の瞬きアニメーションを、`station_scene.png`の中の「空の部分」だけに 限定する（駅舎・プラットフォーム部分には表示させない）

## 要件

- `#starry-sky-bg`に`clip-path`を指定し、星の表示範囲を「空の部分」の 形（L字型）に切り抜く
- 画像編集は行わず、元の`station_scene.png`をそのまま使用する

## 設計方針

`clip-path: polygon()`を用いて、以下の範囲に星の表示を限定する （画像サイズに対する割合、実装後に微調整前提）。

```css
#starry-sky-bg {
  clip-path: polygon(
    0% 0%,
    0% 40%,
    68% 40%,
    68% 20%,
    100% 20%,
    100% 0%
  );
}
```

画像の構図（`station_scene.png`、1774×887px）を踏まえた区切り：

- 左〜中央（横0〜68%、駅名標・ベンチ・花壇・掲示板のあるエリア）： 山並み・街並みのシルエットより上（縦0〜40%）が空
- 右側（横68〜100%、駅舎の建物があるエリア）： 駅舎の屋根の頂点より上（縦0〜20%）だけが空

境界の目視調整のため、実装後に山の稜線・駅舎の屋根に星がかかっていないか 確認し、必要であればパーセンテージを微調整する。

## 判断理由

`clip-path`による範囲限定を採用した理由：

- 画像編集（絵から星を除去する）は、品質劣化のリスクがあり、かつ「夜空の 中の二重表示は問題ない」という方針とは合わなかったため不採用
- コード側だけで完結し、画像アセットに一切手を加えずに済む
- `station_scene.png`は静止画のため、空の範囲（山・建物の輪郭）は変化 しない。座標を一度決めれば、以降調整不要

## 実装メモ

- 対象コード：`index.html` 354行目付近の`#starry-sky-bg`div
- `initStarrySky()`関数・星の生成ロジックは変更不要。`clip-path`の追加のみ
- 前回Codexが実装した「`#nr-station-home-scene`への子要素化」は、 `clip-path`を機能させるための土台として活かせる可能性がある （要確認、そのままでも良いか、ヘッダー基準に戻すべきかは実装時に判断）

## レビュー・フィードバック

### 試行1（表示範囲を絵全体に限定）

依頼した内容は正しく実装されたが、実際には直っていなかった。範囲を絵に ぴったり合わせたことで、絵の中に元々描き込まれている星と、プログラムで 動く星がより正確に重なるようになってしまったため。表示範囲の座標合わせ だけでは解決しない問題であることが判明した。

### 試行2（画像から星を除去）

`station_scene.png`から星を画像編集で除去したが、文字のつぶれ等の品質 劣化があり、かつ「夜空の中の二重表示は問題ない」という方針とも合わない ことが分かり撤回。**方針を「空の範囲だけに星を限定するclip-path」に確定。**

### 試行3（clip-pathによる範囲限定）

ローカルサーバー経由で動作確認。動く星は左〜中央で上部40%、右側で上部 20%に限定され、山の稜線・駅舎の屋根に星がかかっている箇所は確認されな かった。座標の微調整は不要と判断。プラットフォーム・駅舎への星の表示が 解消されたことを確認。
