# ISS-046 BGM音量のバランス調整

|---|---|

|優先度|3 中|

> このテンプレートは「最初から全部埋める」ことを目的としない。 ISSの進行に合わせて少しずつ育てる運用とする。

## 概要

マインドフルネス瞑想機能のBGM（環境音）の音量が、開始の合図音・終了時のシンギングボウルの音に比べてかなり小さい。音量を最大にしないとほぼ聞こえない状態になっており、音量バランスの調整が必要。

## 背景

ISS-041（呼吸パターンのカスタマイズ）のレビュー中に指摘された、呼吸法選択とは無関係な既存の課題。以前から気になっていたとのことで、スコープを分けて別ISSとして起票。

## 目的

BGM（洞窟・せせらぎ・焚火・水琴窟など）と、開始音・終了のシンギングボウルの音量差を解消し、体験全体の音のバランスを整える。

## 要件

- BGM（環境音）のゲイン/音量を、開始音・終了音と自然に感じられるレベルまで引き上げる
- 音量スライダーの可変域や既定値も、調整後のバランスに合わせて見直す

## 設計方針

`index.html`内の音量定数を確認したところ、原因は明確だった。

```js
const AMBIENCE_VOLUMES = { cave: 0.02, brook: 0.008, fire: 0.02, suikinkutsu: 0.02 };
const SINGING_BOWL_VOLUME = 0.2;
```

環境音（BGM）のゲイン値が、シンギングボウルの1/10〜1/25しかない。これが「BGMがほぼ聞こえない」の直接的な原因。対処方針は以下の通り。

- `AMBIENCE_VOLUMES`の各値を、シンギングボウルに対して極端に小さくない範囲まで引き上げる
- 4シーン間の相対バランス（brookが他より控えめ）は維持しつつ、全体を底上げする
- 一発で最適値を決め切るのは難しいため、まず目安の数値で実装してもらい、実際に耳で聞いて微調整する前提とする（ISS-041と同様、反復調整になる可能性が高い）

### 目安の新しい値（初回実装用）

現状比で約6倍を目安に引き上げる。

```js
const AMBIENCE_VOLUMES = { cave: 0.12, brook: 0.05, fire: 0.12, suikinkutsu: 0.12 };
```

## 判断理由

音量スライダー（`breathVolumeMultiplier`）は0〜1の倍率であり、デフォルトは100%（＝倍率1）になっている。つまりスライダーの初期値の問題ではなく、掛け算のベースとなる`AMBIENCE_VOLUMES`自体が小さすぎることが根本原因。ここを直接引き上げるのが最も確実な対処。値の引き上げ幅は、シンギングボウル(0.2)と同レベルまで一気に上げるのではなく、まずは6倍程度の控えめな引き上げに留め、実際に聞いてみてから追加調整する方針とした。音源ファイルごとに収録音量が異なる可能性があるため、4シーンとも同じ倍率で機械的に引き上げるのではなく、実際に聴感で個別調整が必要になる可能性は残る。

## 実装メモ

- `index.html`内の`AMBIENCE_VOLUMES`定数（1857行目付近）の4つの値を、上記の目安値に変更する
- `SINGING_BOWL_VOLUME`・音量スライダー(`breath-volume`)・`breathVolumeMultiplier`のロジックは変更不要（ベースのゲイン値のみ調整すれば解決するはず）
- 変更後、実機で4シーンすべてを再生し、開始音・終了のシンギングボウルと比べて違和感のない音量になっているか確認する

## 実装結果

- Commit：（push後に追記）
- 実装内容：`AMBIENCE_VOLUMES`の値を引き上げ（cave: 0.02→0.12、brook: 0.008→0.05、fire: 0.02→0.12、suikinkutsu: 0.02→0.12）。実機（ローカルサーバー経由）で聴感確認済み、初回の目安値でバランス良好と確認
- 変更ファイル：`index.html`

## レビュー・フィードバック

- 初回に提示した約6倍の目安値で、実機での聴感バランスが良好だった。追加調整は不要

## 懸念事項

- 音源ファイルごとに元々の収録音量が異なる可能性があり、個別調整が必要になるかもしれない（今回は結果的に不要だった）
