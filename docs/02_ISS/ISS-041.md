## 概要

マインドフルネス瞑想機能の呼吸法を、現在の4・7・8呼吸法固定から複数の呼吸法を選択できる形に改修する。デフォルトは腹式呼吸（自分のタイミングで実施、ガイドなし）とし、他の呼吸法を選択した場合のみガイドサークルが該当パターンに合わせて動作する仕組みとする。

## 背景

現状は478呼吸（吸う4秒→止める7秒→吐く8秒）に固定されており、ガイドサークルもこれに合わせて動作する。しかし「止める7秒」が負担に感じるユーザーがいる（開発者自身も含む）ことが分かった。呼吸のペースや向き不向きは個人差が大きいため、複数の呼吸法から選べるようにしたい。

なお本ISSは2026-07-31にISS-027（呼吸法フィールドのモーダル化）の検討過程から派生ISSとして起票されていたもの。当時は「呼吸法の秒数パターンを選択・カスタマイズできるようにする」という粒度だったが、2026-08-12〜13の設計相談で以下の点まで具体化した。

- 対象呼吸法を「腹式呼吸（デフォルト）・4-7-8呼吸法・ボックスブリージング・数息観」の4種に確定
- デフォルトはガイドなしの自分のタイミングで行う腹式呼吸とし、他の呼吸法を選んだ場合のみガイドが動作する、という条件分岐の考え方を導入

## 目的

- ユーザーが自分に合った呼吸法を選べるようにし、瞑想機能の離脱要因を減らす
- デフォルトを最も負担の少ない腹式呼吸（自分のペース）にすることで、初めて使うユーザーへの心理的ハードルを下げる
- 呼吸法ごとにガイドの見た目・動作ロジックを切り替えられる拡張可能な設計にする

## 要件

### 呼吸法一覧（初期実装スコープ）

|呼吸法|説明|ガイド動作|進行方式|
|---|---|---|---|
|腹式呼吸（デフォルト）|鼻から吸う → お腹がふくらむ → ゆっくり吐く|サークルが緩やかに明滅（呼吸周期に非同期のアンビエント演出）|自由（開始/終了のみ）|
|4・7・8呼吸法|吸う4秒 → 止める7秒 → 吐く8秒|サークルの拡縮（フェーズタイマー同期）|自動進行|
|ボックスブリージング|吸う4秒 → 止める4秒 → 吐く4秒 → 止める4秒|サークルの拡縮（フェーズタイマー同期）|自動進行|
|数息観|吐く息ごとに1〜10を数え、10まで行ったら1へ戻る|数字表示＋緩やかな呼吸誘導アニメーション|タップ駆動（吐き終わったらタップしてカウントを進める）|

### 選択UI

- 4つの呼吸法をカード形式で縦 or グリッド配置する（プルダウンは不採用）
- カードをタップして選択すると、その場に説明文がふわっと展開される（アコーディオン的な動き）
- 前回選択した呼吸法を記憶し、次回の初期表示に反映する（未選択時は腹式呼吸がデフォルト）

### 腹式呼吸のガイド演出

強制的なタイミング誘導はしないが、完全にノーガイドだと味気ないため、以下の演出を採用する。

- サークル全体の緩やかな明滅（固定周期・ユーザーの呼吸とは非同期のアンビエント演出）

光の粒子・ペンギン駅長の佇みアニメーションなどの発展案は、初期実装のスコープ外とし別ISSで検討する。

## 設計方針

index.htmlの既存実装（`DEFAULT_BREATH_PHASES` / `startBreathCycle()` / `applyBreathPhase()`）を確認したところ、`startBreathCycle(phases = DEFAULT_BREATH_PHASES)` がすでに「ISS-041から別の配列を渡せるよう」というコメント付きで、フェーズ配列を差し替え可能な設計になっていた。これを踏まえ、以下の方針とする。

- **4・7・8呼吸法・ボックスブリージング**：既存の`startBreathCycle(phases)`をそのまま使う。`{text, sec, scale}`形式の配列を差し替えるだけで対応でき、新規ロジックは不要。ボックスブリージングは以下の配列を新設するのみ。
    
    ```js
    const BOX_BREATH_PHASES = [    { text: "息を吸って", sec: 4, scale: 1.15 },    { text: "止めて",     sec: 4, scale: 1.15 },    { text: "息を吐いて", sec: 4, scale: 0.72 },    { text: "止めて",     sec: 4, scale: 0.72 }];
    ```
    
- **腹式呼吸（デフォルト）**：`startBreathCycle`系（`breathCycleTimer`によるフェーズカウントダウン）を使わない別経路とする。リンゴの拡縮・円環のstroke-dashoffsetアニメーションは起動せず、CSSの緩やかな明滅クラスをリンゴ or 円環要素に付与するだけの軽量関数を新設する。
    
- **数息観**：同じくフェーズタイマーを使わない別経路。`breathing-apple`要素にタップリスナーを新設し、タップ毎にカウントを+1する。表示には既存の`breath-timer-count`要素を「秒数」ではなく「カウント数」表示用に転用する。
    
- **呼吸法選択のconfig化**：`guided: boolean` と `phases | mode` を持つ設定オブジェクトを4パターン分定義し、`toggleMindfulnessTimer()`内でハードコードされている`startBreathCycle(DEFAULT_BREATH_PHASES)`の呼び出しを、選択中パターンに応じた分岐に置き換える。
    
    - `guided: true` かつ `phases`あり → 既存の`startBreathCycle(phases)`を呼ぶ
    - `guided: false`（腹式呼吸）→ フェーズタイマーを起動せず、明滅クラス付与のみ
    - `mode: 'tap'`（数息観）→ タップリスナーを起動し、カウント表示を更新

## 判断理由

既存コードが`startBreathCycle(phases)`という差し替え可能な形ですでに実装されていたため、478・ボックスブリージングは新規ロジックを書かずconfig（フェーズ配列）の追加だけで対応する方針とした。一方、腹式呼吸・数息観はこの「フェーズカウントダウン」の枠組みに乗らない性質（自分のペース／タップ駆動）のため、既存の`breathCycleTimer`とは別の軽量な経路を新設する方が、既存ロジックへの影響（デグレのリスク）を最小化できると判断した。

## 実装メモ

Codexへの実装依頼用メモ。対象ファイルは `index.html`（呼吸ロジック・呼吸モーダルのHTML/CSS/JSがすべて同居している）。

### 1. 定数・configの追加（既存の`DEFAULT_BREATH_PHASES`の直後）

- `BOX_BREATH_PHASES`：`DEFAULT_BREATH_PHASES`と同じ`{text, sec, scale}`形式で、吸う4秒→止める4秒→吐く4秒→止める4秒の4ステップ配列を追加
- `BREATH_PATTERNS`：4呼吸法のconfigオブジェクト
    - `diaphragmatic`：`guided: false`（腹式呼吸、デフォルト）
    - `"478"`：`guided: true, phases: DEFAULT_BREATH_PHASES`
    - `box`：`guided: true, phases: BOX_BREATH_PHASES`
    - `counting`：`guided: true, mode: "tap"`（数息観）
    - 各パターンに`name`（表示名）・`description`（選択時に表示する説明文）を持たせる
- 状態変数を追加：`selectedBreathPattern`（初期値`"diaphragmatic"`）、`countingBreathValue`（初期値`1`）

### 2. 呼吸法選択の分岐ロジック（新規関数）

- `setBreathPattern(patternId)`：`mindfulnessState === 'idle'`のときのみ選択を切り替え、選択中カードのハイライトと説明文表示を更新する
- `setPatternControlsDisabled(disabled)`：セッション中は選択カードを操作不可にする（`setDurationControlsDisabled`と同じ役割を選択カード向けに）
- `startBreathGuideForPattern(patternId)`：分岐の入口。`BREATH_PATTERNS[patternId]`を見て
    - `guided:true`かつ`phases`あり → 既存の`startBreathCycle(phases)`をそのまま呼ぶ（478・ボックス共通、新規ロジック不要）
    - `mode:'tap'` → `startCountingBreath()`
    - それ以外（腹式呼吸） → `startDiaphragmaticGuide()`
- `startDiaphragmaticGuide()` / `stopDiaphragmaticGuide()`：フェーズタイマーを使わず、`breathing-apple`要素に明滅用CSSクラス（例：`is-glowing`）を付与/除去するだけ
- `startCountingBreath()` / `handleCountingBreathTap()` / `stopCountingBreath()`：`breathing-apple`要素にクリック（タップ）リスナーを付け、タップごとに`countingBreathValue`を1〜10で循環させ、`breath-timer-count`表示を更新する

### 3. 既存関数への分岐追加

- `toggleMindfulnessTimer()`：末尾の`startBreathCycle(DEFAULT_BREATH_PHASES)`を`startBreathGuideForPattern(selectedBreathPattern)`に差し替え。あわせて`setPatternControlsDisabled(true)`をセッション開始時に呼ぶ
- `pauseMindfulnessTimer()` / `resumeMindfulnessTimer()`：`BREATH_PATTERNS[selectedBreathPattern]`を見て、`guided+phases`のときは既存の一時停止処理（transform/strokeDashoffsetの固定）、それ以外は明滅クラスの付け外しのみで良い
- `resetMindfulnessTimer()`：`setPatternControlsDisabled(false)`、`stopDiaphragmaticGuide()`、`stopCountingBreath()`を追加で呼ぶ
- `applyBreathPhase()`：フェーズ開始時に`breathing-apple`から`is-glowing`等のガイドクラスを念のため除去（前回セッションの残留防止）

### 4. HTML（呼吸モーダル内、`breathing-duration-selector`の直前）

呼吸法選択カードを4つ（2×2グリッド想定）と、その下に説明文表示用の要素を追加する。カードは`data-pattern`属性でパターンIDを持たせ、クリックで`setBreathPattern`を呼ぶ。

### 5. CSS

- `.breathing-apple.is-glowing`：`box-shadow`や`filter: drop-shadow`をゆっくり強弱させるkeyframeアニメーション（6〜8秒程度の周期、ユーザーの呼吸とは非同期）
- `.breathing-apple.is-tappable`：`cursor: pointer`
- `.breathing-apple.is-tapped`：タップ時の一瞬の拡大フィードバック（0.3〜0.4秒程度）
- 呼吸法選択カードの選択状態スタイル（既存の`.breathing-duration-btn.is-selected`と同じ配色に揃える）
- `prefers-reduced-motion: reduce`のユーザー向けに明滅アニメーションを無効化する分岐も忘れずに

### 6. 動作確認の観点

- 4パターンすべてで開始→一時停止→再開→リセットが破綻しないこと
- 数息観でタップ判定が正しく1〜10を循環すること、10の次で1に戻ること
- セッション中に呼吸法選択カードが操作不可になっていること
- `prefers-reduced-motion`環境で明滅アニメーションが止まること

## レビュー・フィードバック

Codexによるv1実装後、実機（PC/スマホ）で確認したところ以下のフィードバックが挙がった（2026-08-15）。v2として要件・実装メモを追加する。

1. **レイアウト**：スマホ表示でモーダルが一画面に収まらない。呼吸法選択カードの説明文を常時表示にしたことで縦スペースを圧迫している。当初設計の「タップ時のみ説明文を展開」に戻す
2. **数息観**：タップの意味が「吐き終わり」になっていたが、正しくは「吐き始め」にタップする形にしたい。またタップ時に数え言葉（ひとつ、ふたつ…）を一音ずつ表示する演出が欲しい
3. **腹式呼吸**：明滅演出がappleのみだったが、リング（円環）にも同期した明滅が欲しい。ガイド文言「自分のペースで」も、腹式呼吸を促す一言に変えたい
4. **ボックスブリージング**：円形ガイドのままだったが、本来のボックス呼吸に合わせて正方形のガイド（1辺＝1フェーズ4秒で描画）にしたい

## 懸念事項

- 数息観のタップ判定精度（誤タップ・タップ漏れへの対処）

## 要件（v2追加）

### レイアウト

- 呼吸法選択カードの説明文は、選択時のみアコーディオンで展開する（常時表示に戻さない）

### 数息観

- タップの意味を「吐き終わり」から「吐き始め」に変更し、ガイド文言も「吐き始めにタップ」に修正する
    
- タップ時に、その回の数え言葉を一音ずつ区切ったテキストを表示する（フェードイン/アウト程度の軽い演出）。読みの目安は以下（区切り方は実装時に調整可）：
    
    |回数|表示テキスト（案）|
    |---|---|
    |1|ひー・とー・つー|
    |2|ふー・たー・つー|
    |3|みー・っ・つー|
    |4|よー・っ・つー|
    |5|いー・つー・つー|
    |6|むー・っ・つー|
    |7|なー・なー・つー|
    |8|やー・っ・つー|
    |9|こー・こー・のー・つー|
    |10|とー・おー|
    
- 数息観の選択時説明文に、開始前の下準備として「①姿勢を整える ②最初に口から一度しっかり息を吐ききる」を短く追記する（セッション中に毎回表示するのではなく、選択時の説明文のみに含める）
    

### 腹式呼吸

- `breathing-progress-value`（リング）にも`is-glowing`相当の明滅アニメーションを追加し、appleと同期させる
- ガイド文言を「自分のペースで」から「お腹をふくらませて、ゆっくり吐いて」に変更（固定表示のまま。タイミングを強制する演出は追加しない）

### ボックスブリージング

- 円形のリングではなく、正方形のガイドに変更する
- 1辺＝1フェーズ（4秒）とし、フェーズが進むごとにその辺が光りながら描画される（既存の`stroke-dashoffset`によるリング描画と同じ技法を、四角形のpathまたは4本のlineに応用する）
- `BREATH_PATTERNS.box`に`shape: "square"`のようなフラグを追加し、ガイド要素の出し分け（circle表示 or square表示）を行う

## レビュー・フィードバック（v3・2026-08-15）

v2実装（レイアウト・数息観のタップ意味/音声ガイド・腹式呼吸のリング明滅/文言・ボックスの正方形化）を確認した上での追加フィードバック。なお、確認前に発生していた「画面全体が拡大されて見える」事象はブラウザの表示倍率設定が原因と判明（Ctrl+0でリセットして解消）。コード起因ではなかったため懸念事項からは解消済みとする。

1. **レイアウト（依然未解決）**：モーダルがまだ1画面に収まらずスクロールが必要。BGM切り替え・音量スライダーまで画面内に入りきっていない
2. **腹式呼吸**：ダークモードでリンゴ・ガイドサークルの色変化がわかりづらい。ライト/ダーク問わず「サークルの色変化」自体が分かりづらい。案として「サークルが徐々に消えて見えなくなり、ゆっくり復活する」という不透明度ベースの演出なら、邪魔にならず変化も感じられそう。ガイド文言も「呼吸を観察しましょう」に短縮したい
3. **数息観**：「ひー・とー・つー」の表示テンポが速すぎるので、もっとゆっくり表示してほしい。また数字（1〜10）よりも読み仮名の文字の方が小さいが、役割は同じなので数字は省略するか目立たなくし、読み仮名側を大きく主役にしたい

## 要件（v3追加）

### レイアウト（再調整）

- 選択後のパターン・時間表示をチップ状に折りたたむなど、より積極的な省スペース化を行う
- モーダルは「スクロール可能なコンテンツ領域」＋「下部固定（sticky）のスタート/リセットボタン」という構成に変更し、BGM選択・音量スライダーを含めた全コントロールにスマホでも到達できるようにする
- BGM選択（洞窟・せせらぎ・焚火・水琴窟・自動）と音量スライダーも、呼吸法選択カードと同様にコンパクトな表示に見直す

### 腹式呼吸（再調整）

- リング（`breathing-progress-value`）の明滅演出を、色・発光ベースの`is-glowing`から**不透明度（opacity）ベースのフェード演出**に変更する。ゆっくり薄くなって見えなくなり、ゆっくり元の濃さまで復活する、というサイクル（周期の目安は元の`is-glowing`と同程度、6〜8秒）。ライト/ダーク双方で視認性が同等になることを優先する
- apple側の色変化・発光効果は、ダークモードでの視認性問題の原因になっているため一旦削除し、静止表示のシンプルなアイコンに戻す（拡大縮小もしない）。明滅演出はリング側のみに一本化する
- ガイド文言を「お腹をふくらませて、ゆっくり吐いて」から「呼吸を観察しましょう」に変更する

### 数息観（再調整）

- 数え言葉の表示テンポを大幅に緩める。目安：フェードイン0.4秒 → 表示保持1.6秒程度 → フェードアウト0.4秒（合計2.4秒程度、次のタップまで表示され続けても良い）
- 数字カウント（`breath-timer-count`）表示は削除するか、隅に小さく補助的に残す程度に縮小する
- 読み仮名テキスト（「ひー・とー・つー」等）を主役として大きく表示する
