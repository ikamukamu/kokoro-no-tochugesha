|項目|内容|

> このテンプレートは「最初から全部埋める」ことを目的としない。 ISSの進行に合わせて少しずつ育てる運用とする。

## 概要

マイコーピング機能に「一覧表示・編集・削除」を追加する。現状はランダムピック アップのみのため、利用者が自分の登録したコーピングを把握・管理できない状態に なっている。ISS-031〜034の中で最初に着手する、基盤となるタスク。

2026-08-17〜21の設計相談を経て、本ISSのスコープを**コーピングタブ全体の ナビゲーション再設計**まで拡張した。状態選択（5カテゴリ）はプリセット提案・ マイコーピング一覧の両方に関わる共通の入口であるため、マイコーピングの 一覧・詳細だけでなく、タブ全体の画面構成をあわせて設計する。

## 背景

チャピとの相談の中で、黒子から「今はランダムピックアップのみだと、ユーザーは 自分が何を登録したか把握できず、編集・削除もしづらい」という指摘があった。 チャピもこれに賛成し、「駅長のヒント」（プリセットの提案）と「わたしのコーピング」 （自分の登録物）を明確に分けるべき、という方向性で一致した。

現状のコーピング機能は「提供する」ことに寄っており、「利用者が自分だけのお守りを 集めて育てる」という方向へ軸足を移していく最初のステップとして位置づける。

さらに2026-08-17、実装済みの`copingSkillsDatabase`の5カテゴリ（⚡動悸・緊張・ 心臓バクバク／😡怒り・理不尽なイライラ／🏆完璧主義「ねばならない」の罠／ 👥他人の目（嫌われてるかも犬）／🔋意欲低下・おっくう・体が動かない）が、 ISS-034.mdに記載されていた初期プラン（ストレスから離れる、など方法・行動 ベースの5分類）と一致していないことが判明した。実際のカテゴリは「今の症状・ 状態」という単一の軸で揃っており、この状態ベースの入口自体は機能的に妥当と 判断し、維持する方針とした（詳細は[[コーピング機能刷新構想]]参照）。

## 目的

- ランダム表示を「提案モード」、一覧表示を「管理モード」として明確に分離する
- 利用者が「わたしのコーピング帳」として、自分の登録物を把握・編集・削除できるようにする
- 「途中下車」の世界観に沿った、自分だけのお守りを集めていく体験の土台を作る

## 要件

### コーピングタブ全体のナビゲーション

- 状態カテゴリ（5つ：動悸／怒り／完璧主義／他人の目／意欲低下）を、アイコン＋短いラベルの**横並びタブ**として画面上部に常駐させる（デフォルト選択は「動悸」）
- タブ選択中の状態には、簡単な補足説明テキストを表示する（例：「動悸：ドキドキしていて すぐに助けてほしいとき」）
- 補足テキストの右に、新規マイコーピング登録への「＋」ボタンを配置する（ISS-032の登録導線に接続）
- 現行のランダム抽選（3件表示）は**撤廃する**。コーピングは「今すぐ実行可能な行動」を選ぶものであり、文脈とズレた提案は無価値なため、一覧から選べる形に一本化する（「おみくじ的な別機能として残す」案は本ISSのスコープ外とし、[[コーピング機能刷新構想]]に保留事項として記録する）

### 一覧表示（タブ配下）

- タブ配下に、フィルタ（全部／自分のみ／既存のみ／お気に入り）を横並びで表示する。主従は作らない。デフォルト（全部表示）ではユーザー登録のコーピングが上位に来るようソートする
- フィルタの下に、コーピング一覧をアコーディオンUIで表示する（タイトルのみを折りたたんだ状態で並べる）
- 一覧内で「駅長のヒント（プリセット）」と「わたしのコーピング（自分の登録）」が視覚的に区別できるようにする

### 詳細表示（アコーディオン展開）

- タイトルをタップすると、別画面に遷移せず、その場でアコーディオンが展開して詳細を表示する
- 詳細には、説明テキスト・図説（写真、あれば）・「使用した」ボタンを表示する
- マイコーピングの場合のみ：編集・削除ボタンを表示する
- プリセットの場合のみ：「＋マイコーピングに追加」ボタンの**置き場所を確保**する（実際の追加処理はISS-033で実装。本ISSでは配置のみ）

### 使用ログの記録（新規）

- 「使用した」ボタンを押すと、きっぷ保管庫に使用記録を残す（日時・どのコーピングを使ったか）
- ボタンの文言は「使用した」で仮置きし、最終決定は保留（要検討）

### 並び替え・データ構造

- 並び替え機能（詳細は設計方針で検討）
- 個別の削除機能
- 個別の編集機能（ISS-032の「一次登録→後で編集」と連携する前提で設計する）

## 設計方針

「わたしのコーピング帳」という世界観に合わせたUIを検討する。単なる「管理画面」 ではなく、駅長の世界観（[[世界観]]参照）と一貫性のある見せ方にする。

詳細な方針は [[コーピング機能刷新構想]] を参照。本ISSの設計は同構想の 以下の内容を前提とする。

### 画面構成（確定・2026-08-21）

```
┌────────────────────────────────────┐
│ [⚡][😡][🏆][👥][🔋]                  │ ← 状態アイコンタブ（横並び、デフォルト＝動悸）
├────────────────────────────────────┤
│ 動悸：ドキドキしていてすぐに助けて    ＋│ ← 選択中タブの補足テキスト＋追加登録
│ ほしいとき                            │
├────────────────────────────────────┤
│ 全部｜自分のみ｜既存のみ｜お気に入り    │ ← フィルタ（横並び）
├────────────────────────────────────┤
│ ▸ コーピングタイトルA                  │
│ ▸ コーピングタイトルB                  │ ← アコーディオン一覧
│ ▸ コーピングタイトルC                  │
└────────────────────────────────────┘

タップで展開（別画面遷移なし）
┌────────────────────────────────────┐
│ ▾ コーピングタイトルB                  │
│   説明テキスト                         │
│   図説（写真）                         │
│   [使用した]                          │
│   （マイコーピング：編集／削除）         │
│   （プリセット：＋マイコーピングに追加） │← ISS-033用の置き場所のみ確保
└────────────────────────────────────┘
```

- 画面遷移ではなく、1画面内でタブ（左右ではなく上部横並び）と内容（アコーディオン）が連動する構成のため、実装はシンプルになる見込み
- 状態タブの切り替え時は、フィルタ・一覧の開閉状態をリセットする（前の状態のアコーディオン展開状態を引き継がない）

### データ・表示方針（従来通り維持）

- **表示はフィルタ方式**：全部／自分のみ／既存のみ／お気に入り、を切り替え 可能にする。主従は作らない。デフォルト（全部表示）ではユーザー登録の コーピングが上位に来るようソートする
    
- **データは「タイトル＋詳細」の2階層**：一覧はタイトルのみを付箋のように 並べ、クリックで詳細を表示する
    
- **タグは複数持てるデータ構造にしておく**：UI上は初回登録時に必須にしない （表側は簡単に、裏側は拡張可能に）
    
- 一覧のソート順（登録順／最終使用日／五十音順など）は要検討
    
- 将来的な「育つコーピング帳」構想（最終使用日・使用頻度の表示など）とデータ 構造がぶつからないよう、ISS-031時点でのデータ設計に余地を持たせる （※育つコーピング帳自体は本ISSのスコープ外、[[ISS-034]]や将来ISSで検討）
    
- 「使用した」ボタンの記録は、上記の「最終使用日・使用頻度」データと同じ 仕組みで蓄積される想定。データ構造設計時にあわせて検討する

## レビュー・フィードバック（v1・2026-08-21）

初回実装を実機で確認した上でのフィードバック。8点。

1. **アプリ名**：「わたしのコーピング帳」だと自作登録前提の語感が強い。既存プリセットのみ使う人も想定し「コーピング手帳」に変更
2. **サブタイトル**：「今の状態を選び、できそうなことを探してみましょう」は目的（効果があるものを探す）とズレている。「今、どんな状態？」という問いかけのみに簡略化
3. **5つの状態分類**：状態から選ぶ導線はイメージのしやすさが重要なため、オノマトペを使った名称に再編
4. **説明テキスト**：カテゴリ再編にあわせて全面的に作り直し
5. **フィルタ表記**：「全部／自分のみ／既存のみ／お気に入り」を、より分かりやすい表記に変更
6. **「駅長のヒント」ラベル**：視覚的にバッジとして認識できているか確認したい（実装後の見た目次第で保留）
7. **一覧の表示件数**：フィルタに関わらず、どの状態を選んでも3件しか表示されない不具合（旧ランダム抽選の名残と思われる）
8. **「使用した」ボタン**：押した後の挙動（記録に残る）が文言から想像しにくい。「＋マイコーピングに追加」ボタンとのサイズバランスも悪い

## 要件（v2追加）

### アプリ名・サブタイトル

- タイトルを「わたしのコーピング帳」から**「コーピング手帳」**に変更する
- サブタイトルを「今の状態を選び、できそうなことを探してみましょう。」から**「今、どんな状態？」**のみに変更する

### 5つの状態分類（表示名の変更）

状態タブの表示名・アイコンを以下に変更する。データ上の対応関係（どのプリセット・タグがどの状態に属するか）は変更しない。

|旧表示名|新表示名|
|---|---|
|⚡ 動悸・緊張・心臓バクバク|⚡ バクバク心臓|
|😡 怒り・理不尽なイライラ|😡 イライラ気分|
|🏆 完璧主義「ねばならない」の罠|🏆 ガチガチ思考|
|👥 他人の目（嫌われてるかも犬）|👥 チクチク視線|
|🔋 意欲低下・おっくう・体が動かない|🔋 ポッカリ虚無|

**注意**：`copingSkillsDatabase`のキーやマイコーピングの`stateTag`に、旧カテゴリ名の文字列（例：「⚡ 動悸・緊張・心臓バクバク」）がそのまま使われている場合、表示名だけを変えるか、データのキー自体をリネームするかは実装時に判断してよい。ただし、既存のマイコーピング登録データ（stateTagで紐付いているもの）が表示上「該当なし」にならないよう、対応関係が壊れないことを最優先にする。

### 補足テキスト（新カテゴリ対応）

各状態タブ選択時の補足テキストを、以下に差し替える。

- バクバク心臓：ドキドキして、すぐにでも落ち着きたいとき
- イライラ気分：怒りやモヤモヤが抑えきれないとき
- ガチガチ思考：「こうしなきゃ」に縛られて動けないとき
- チクチク視線：人の目が気になって、居心地が悪いとき
- ポッカリ虚無：やる気が出ず、何も手につかないとき

### フィルタ表記の変更

- 表示ラベルを「全部／自分のみ／既存のみ／お気に入り」から**「すべて表示／マイコーピング／既存のコーピング／お気に入りのみ」**に変更する（絞り込みロジック自体は変更しない）

### 一覧の全件表示（不具合修正）

- 現状、状態やフィルタに関わらず一覧が3件までしか表示されない不具合を修正する。旧ランダム抽選（3件表示）の実装が一部残っている可能性が高いので確認すること
- フィルタ条件に合致する**すべて**の項目を一覧に表示する

### 「使用した」ボタンの変更

- ボタンの文言を「使用した」から**「やってみた」**に変更する
- 「＋マイコーピングに追加」ボタンとサイズ（高さ・パディング）を揃え、見た目のバランスを整える

## レビュー・フィードバック（v2・2026-08-21）

v2実装を実機で確認した上でのフィードバック。

1. **状態アイコン**：ガチガチ思考がトロフィーのままなど、ラベルの語感と合っていないアイコンが残っている
2. **補足説明**：短すぎて情景が浮かびにくい
3. **＋ボタンの分かりづらさ**：丸いアイコンのみのボタンだと、新規登録の入口だと伝わりにくい
4. **フィルタボタンの見た目**：選択中が真っ黒になり、状態タブ（ピンク系）とのギャップが大きい。枠ありボタンではなく、文字＋下線のシンプルな見た目が良い。また状態タブを切り替えるとフィルタ選択がリセットされてしまうが、記憶しておく方が自然。表記も「既存のコーピング」→「おすすめコーピング」、「お気に入りのみ」→「お気に入り」に変更したい
5. **3件しか表示されない不具合が未解決**：旧ランダム抽選のロジック（`candidatePool.slice(0, 3)`）が新しい一覧レンダリングに残っている可能性が高い
6. **ヒット数表示**：フィルタ条件に応じて可変する件数を表示したい。総数が見えることで「コーピングは多いほど良い」という価値観も伝えられる
7. **タイトル・世界観の位置づけ**：「コーピング手帳」は「育てていく」印象が強く、このリストが持つ「ピンチの時の特効薬」という位置づけが伝わりにくい。「コーピング処方箋」に戻し、病院・処方箋の世界観に寄せる方針とした

## 要件（v3追加）

### 状態アイコンを色分けカプセルに統一

- 5つの状態アイコンを、絵文字の個別選定ではなく、**色分けしたカプセル（錠剤）型のアイコン**に統一する
- 絵文字の`💊`は色を変更できないため、SVGまたはCSSで自作するカプセル型アイコン（実装方法は任せる）とする
- 色の割り当て：
    - バクバク心臓：赤
    - イライラ気分：橙
    - ガチガチ思考：グレー
    - チクチク視線：紫
    - ポッカリ虚無：青

### タイトルを「コーピング処方箋」に戻す

- タイトルを「コーピング手帳」から**「コーピング処方箋」**に戻す
- サブタイトル「今、どんな状態？」はそのまま維持する
- カード全体を「処方箋」の世界観に寄せる（既存のカードアイコンが医療系デザインのため、大きな変更は不要と想定されるが、状態アイコンのカプセル化とあわせて統一感を出す）

### 補足説明テキストを詳しく

- 5つの補足テキストを、もう少し情景が浮かぶ長さ・具体性に調整する（大まかな方向性のみ指定。具体的な文言はCodexの提案でも可、迷う場合は確認すること）

### ＋ボタンの分かりやすさ改善

- 丸いアイコンのみの「＋」ボタンをやめ、「＋追加登録」のようにテキストを添えた横長ボタンに変更する

### フィルタの見た目・挙動修正

- フィルタボタンを、枠ありのボタンから**文字＋下線（アンダーライン）**のシンプルなスタイルに変更する
- 状態タブを切り替えても、選択中のフィルタが**リセットされず維持される**ようにする
- 表記を変更する：「既存のコーピング」→**「おすすめコーピング」**、「お気に入りのみ」→**「お気に入り」**

### 3件制限の不具合修正（再指示）

- 旧ランダム抽選ロジックの`candidatePool.slice(0, 3)`（および同様の`.slice(0, 3)`パターン）が、新しい一覧表示のレンダリング関数に残っていないか確認し、削除する
- フィルタ条件に合致する全件が表示されることを実機で確認すること

### ヒット数の表示

- フィルタ・状態の絞り込み条件に応じて可変する件数（例：「3件」）を、一覧の近くに表示する

## レビュー・フィードバック（v3・2026-08-21）

v3実装を実機で確認した上でのフィードバック。

1. **状態タブのアイコン**：カプセル型アイコンは何の状態か分かりづらい。状態を表す意味のあるアイコン（ハート／怒り／鎖／人型／電池）に戻したい。ただし**タブの見た目（角の丸み）はカプセルらしい形にしたい**（アイコンの中身と、ボタンの形は別の話として切り分ける）
2. **補足説明テキストの配色**：濃いグレーの背景に白抜き文字にしたい
3. **「＋追加登録」ボタンの配色**：白背景に赤文字にしたい（現状は赤背景の塗りつぶし）
4. **新規追加フォームのアイコン**：状態タグのドロップダウン内アイコンが旧タイプ（⚡😡🏆👥🔋）のまま。新アイコンに統一する必要がある。また「新規追加」というタイトルテキストの前に、薬箱のアイコンを追加したい
5. **3件しか表示されない不具合が、3回目の指示でも直っていない**：`candidatePool.slice(0, 3)`の削除を指示したが解決していない。原因箇所の特定をさらに徹底する必要がある
6. **「件」という表現**：他の言い回しにできないか検討したい（良い案がなければ「件」のままで良い）
