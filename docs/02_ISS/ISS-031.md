# ISS-031 マイコーピング一覧（閲覧・編集・削除）

## 概要

マイコーピング機能に「一覧表示・編集・削除」を追加する。現状はランダムピック
アップのみのため、利用者が自分の登録したコーピングを把握・管理できない状態に
なっている。ISS-031〜034の中で最初に着手する、基盤となるタスク。

## 背景

チャピとの相談の中で、黒子から「今はランダムピックアップのみだと、ユーザーは
自分が何を登録したか把握できず、編集・削除もしづらい」という指摘があった。
チャピもこれに賛成し、「駅長のヒント」（プリセットの提案）と「わたしのコーピング」
（自分の登録物）を明確に分けるべき、という方向性で一致した。

現状のコーピング機能は「提供する」ことに寄っており、「利用者が自分だけのお守りを
集めて育てる」という方向へ軸足を移していく最初のステップとして位置づける。

## 目的

- ランダム表示を「提案モード」、一覧表示を「管理モード」として明確に分離する
- 利用者が「わたしのコーピング帳」として、自分の登録物を把握・編集・削除できるようにする
- 「途中下車」の世界観に沿った、自分だけのお守りを集めていく体験の土台を作る

## 要件

- マイコーピングの一覧表示（登録済みのコーピングをすべて表示）
- 並び替え機能（詳細は設計方針で検討）
- 個別の削除機能
- 個別の編集機能（ISS-032の「一次登録→後で編集」と連携する前提で設計する）
- 「駅長のヒント（プリセット）」と「わたしのコーピング（自分の登録）」を画面上で
  明確に分離する

## 設計方針

「わたしのコーピング帳」という世界観に合わせたUIを検討する。単なる「管理画面」
ではなく、駅長の世界観（[[世界観]]参照）と一貫性のある見せ方にする。

詳細な方針は [[コーピング機能刷新構想]] を参照。本ISSの設計は同構想の
以下の内容を前提とする。

- **表示はフィルタ方式**：全部／自分のみ／既存のみ／お気に入り、を切り替え
  可能にする。主従は作らない。デフォルト（全部表示）ではユーザー登録の
  コーピングが上位に来るようソートする
- **データは「タイトル＋詳細」の2階層**：一覧はタイトルのみを付箋のように
  並べ、クリックで詳細を表示する
- **タグは複数持てるデータ構造にしておく**：UI上は初回登録時に必須にしない
  （表側は簡単に、裏側は拡張可能に）

- 一覧のソート順（登録順／最終使用日／五十音順など）は要検討
- 将来的な「育つコーピング帳」構想（最終使用日・使用頻度の表示など）とデータ
  構造がぶつからないよう、ISS-031時点でのデータ設計に余地を持たせる
  （※育つコーピング帳自体は本ISSのスコープ外、[[ISS-034]]や将来ISSで検討）
