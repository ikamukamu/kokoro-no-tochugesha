# ISS-060 各機能の使い方案内整備

| --- | --- |

> このテンプレートは「最初から全部埋める」ことを目的としない。
> ISSの進行に合わせて少しずつ育てる運用とする。

## 概要

「ご案内」モーダルの使い方案内を、現在の4機能の簡易表から、アプリ内の主要7機能を
それぞれ理解できる内容へ拡充する。

## 背景

[[ISS-059]]の検討時に、現在の案内では機能が網羅されておらず、各機能の説明が
必要という要望が出た。説明文の内容設計には個別の確認が必要なため、操作性改善とは
分離し、一旦保留とする。

## 目的

- 初めて利用する人が、各機能の役割と使いどころを理解できるようにする
- 機能名だけでは用途が分かりにくい項目を、平易な言葉で案内する

## 要件

以下の7機能について、それぞれ説明を用意する。

- コーピング
- セルフトーク
- コラム法
- 良いこと日記
- 言葉サプリ
- きっぷ保管庫
- マインドフルネス瞑想

各説明には、少なくとも以下を含める。

- どんな機能か
- どんなときに使うか
- 利用すると何ができるか

## 説明文案 v2（確定）

2026-09-24にユーザー確認を経て確定。v1はこのv2で置き換えた。
カードの並び順は、切符ナビの並び（コーピング→きっぷ保管庫）に、切符ナビ外導線の
マインドフルネス瞑想を末尾として続ける。

### コーピング

**何ができる？** いまのストレス状態に合わせて、気持ちや体を少し楽にするための
具体的な行動を探せます。自分用のコーピングを追加・編集もできます。

**こんなときに：** 緊張、怒り、つらさ、何もする気が起きないときなど

### セルフトーク

**何ができる？** 今の悩みや気持ちを書き、選んだ相談相手（6キャラのAI）から
言葉を受け取れます。心に残った言葉は「お守り」として保存できます。

**こんなときに：** 誰かに話を聞いてほしいとき、自分を責めすぎているとき、
自分への声掛けをしたいとき

### コラム法

**何ができる？** 出来事、気持ち、そのとき浮かんだ考えを順番に書き出し、
別の見方がないか整理できます。5項目のライト版と7項目の標準版を選べます。

**こんなときに：** 考えが頭から離れないとき、思い込みが強くなって苦しいとき

### 良いこと日記

**何ができる？** その日にあった良かったことを3つ記録し、一日の中にあった
小さな良い出来事を振り返れます。

**こんなときに：** 気持ちを整えたいとき、良かったことに目を向ける習慣を
つくりたいとき

### 言葉サプリ

**何ができる？** 心の状態やテーマに合わせて、考え方のヒントになる短い言葉を
読めます。「今日の栄養」として、日替わりで一つ自動表示もされます。

**こんなときに：** 気持ちを切り替えるきっかけがほしいとき、自分に合う言葉を探したいとき

### きっぷ保管庫

**何ができる？** セルフトークで保存したお守り、コラム法の記録、良いこと日記等を
まとめて見返せます。

**こんなときに：** 過去の記録を振り返りたいとき、以前自分を助けてくれた言葉や
考え方を確認したいとき。

### マインドフルネス瞑想

**何ができる？** 4種類の呼吸法から自分に合うものと時間を選び、画面のガイドと
環境音に合わせて呼吸を整えて、心身を落ち着けるための時間をつくれます。

**こんなときに：** 緊張をゆるめたいとき、考えから少し距離を置きたいとき、
短い時間ですっきりしたいとき。

## 表示構成案

- [[ISS-059]]で作成した「使い方のご案内」アコーディオン内に7枚のカードを並べる
- **現在の4機能テーブル（切符名／こんなとき／効果）は削除し、7枚のカードへ全面置換する**
- 各カードは「機能名」「何ができる？」「こんなときに」の3要素で統一する
- 7機能を個別の入れ子アコーディオンにはせず、使い方案内を開いたら一覧できる形にする
- 各カードの先頭には、下表の配色を色帯またはアイコン色として付ける
- Gemini APIが必要な補助機能については、カード本文を複雑にしないため、一覧の末尾に
  共通注記としてまとめることを検討する

### カード配色（暫定）

機能の性格で3グループに分け、識別しやすさを優先した暫定配色とする。
恒久的な配色ではなく、後から可変させる前提。

| 機能 | 色グループ | 性格 | Tailwindクラスの目安 |
| --- | --- | --- | --- |
| コーピング | ローズ | いま、気持ちを楽にする | `text-pdPink` / `border-pdPink` |
| セルフトーク | ローズ | いま、気持ちを楽にする | `text-pdPink` / `border-pdPink` |
| コラム法 | ティール | 書いて整理する | `text-teal-700` / `border-teal-600` |
| 良いこと日記 | ティール | 書いて整理する | `text-teal-700` / `border-teal-600` |
| 言葉サプリ | アンバー | 読む・見返す | `text-amber-600` / `border-amber-500` |
| きっぷ保管庫 | アンバー | 読む・見返す | `text-amber-600` / `border-amber-500` |
| マインドフルネス瞑想 | ローズ | いま、気持ちを楽にする | `text-pdPink` / `border-pdPink` |

既存表示との差異（本ISSで変更されるもの）

- セルフトーク：現行の使い方テーブルでは`text-amber-600` → ローズへ
- 良いこと日記：現行の使い方テーブルでは`text-blue-900`（寝台乗車券の青） → ティールへ
- きっぷ保管庫：切符ナビでは`text-teal-700` → アンバーへ

上記はご案内モーダル内のカード配色のみの変更であり、切符ナビ本体の配色は変更しない。

## 設計方針

- 一般利用者向けの平易な表現を使い、専門用語や実装用語を避ける
- 医療上の診断・治療を行う機能と誤認されない表現にする
- [[ISS-059]]で用意する「使い方のご案内」アコーディオン内へ掲載する
- 機能ごとの簡潔なカードを縦に並べ、入れ子のアコーディオンは使わない
- 各カードは「何ができる？」「こんなときに」の2項目で表現を統一する
- 配色は3グループの暫定配色とし、切符ナビ本体の配色には手を入れない

## 判断理由

説明文の作成には各機能の役割・世界観・表現の確認が必要であり、レイアウト変更と
同時に決めると範囲が広がるため、独立したISSとして保留する。

v2確定時の判断は以下の通り。

- **言葉サプリ**：実装（`initDailyWord()`）は`new Date().getDate()`で日にちから
  言葉を決めており、ランダムではなく日替わりの固定表示。文案側を「日替わりで一つ
  自動表示」に修正した。画面上の表記「［ランダムで自動表示します］」は実装と
  食い違っているが、本ISSでは触らない
- **マインドフルネス瞑想**：「心身の安定を得られます」は効果を断定する表現となり、
  完了条件の「医療機能と誤認されない表現」に抵触しうるため、「心身を落ち着けるための
  時間をつくれます」へ変更した

## 懸念事項

- 説明量が増えすぎると、ご案内モーダルが再び長くなる
- 「言葉サプリ」「きっぷ保管庫」など世界観由来の名称は、機能名と役割の両方を
  説明する必要がある
- 4行テーブルは横1行で複数機能を見比べられたが、カード7枚は縦に伸びるため、
  アコーディオンを開いた後のスクロール量が増える
- 言葉サプリ画面の「［ランダムで自動表示します］」は実装（日替わり固定）と
  食い違ったままになる。別途の修正要否を判断する必要がある
- きっぷ保管庫の説明にある「等」は、マイコーピングの管理ときろくのお守り
  （バックアップの書き出し・読み込み）を含む。明示するかは未決
