# ISS一覧

コーピング機能に関わる各ISSへの索引。バックログの運用ルール（優先順位の 決め方・状態の定義など）は [[次の停車駅]] を参照。

## マイコーピング再構成（ISS-031〜034）

チャピ・黒子との相談をもとに、マイコーピング機能の再構成を4件のISSに分割。 背景・目的の全体像は [[コーピング機能刷新構想]] を参照。

| ISS         | 状態  | 優先度 | 概要                                                 |
| ----------- | --- | --- | -------------------------------------------------- |
| [[ISS-031]] | 設計中 | 高   | マイコーピング一覧（閲覧・編集・削除）。「駅長のヒント」と「わたしのコーピング」を分離する基盤タスク |
| [[ISS-032]] | 検討中 | 高   | コーピング登録UX改善。タイトルのみの一次登録、後から編集、登録導線                 |
| [[ISS-033]] | 検討中 | 中〜高 | プリセットをマイコーピングとして登録。「そのまま追加」「編集して追加」の両方を扱う          |
| [[ISS-034]] | 検討中 | 中   | コーピングのタグ・分類の仕組み。複数タグ対応のデータ構造への移行                   |

### 依存関係

```
ISS-031（一覧・編集の基盤）
    ↓
ISS-032（登録UX、031のデータ構造を前提）
    ↓
ISS-033（プリセットからの追加、031・032の両方を前提）

ISS-034（タグ構造・データ移行）は031と並行して検討可能。
ただしISS-031の一覧・フィルタ表示とタグ構造が連動するため、
実装時期はISS-031の進捗と合わせて調整する。
```

着手順序の目安：ISS-031 → ISS-032 → ISS-033。ISS-034は並行検討可だが、 データ移行を伴うため着手タイミングは慎重に判断する。
