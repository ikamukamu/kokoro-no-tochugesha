効果やエビデンスの扱いは、題材によって決める。

- 読者（リワーク参加者・修了者）がプログラムで既に毎日実践している題材（マインドフルネス瞑想など）は、効果の説明を省き、アプリ側の意図と使い方に絞る。改めて必要性を説くのは烏滸がましいため
- プログラムで扱っていない題材は、客観的なエビデンス（研究・データ等）が活きる余地がある。使う場合は、書く段階で実際の文献等を確認してから記載する（不確かな情報を確信ありげに書かない）

- サイズ：A4片面、縦（表裏2ページ化は当面見送り）

- 見出しは「01．」「02．」「03．」の通し番号形式で統一し、**各見出しの右に内容を表すアイコンを置く**（#3：01＝葉、02＝シャッフル、03＝タイプライター）
- 01＝機能紹介（機能に込めた意図と使い方をシンプルに）、02＝アップデート情報（説明不要・簡潔に）、03＝開発日誌（裏話・展望＋深い使い方の補足。日常回は例外扱いで手書き風タグを添える）という役割分担

- 文体は「です・ます」を土台に、少し崩した親しみのある調子（#3で確定）
- 機能ピックアップは持ち回り制。当初は #2〜#6 の5号で6機能を一巡させる計画だったが、#3でリストに無い呼吸法を扱ったため1号ぶん後ろにずれている
