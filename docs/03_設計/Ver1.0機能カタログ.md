### 保存系の技術メモ（Ver1.0時点）

- 保存系は、ローカル記録・クラウド記録・バックアップ対象キーがコード上で
  分かれており、CBT／セルフトーク／良いこと日記の3系統を扱う
- クラウド側はFirebase認証後にFirestoreの`cbt_records` / `talk_records` /
  `threegoods_records`を購読する構成
- API設定はGemini APIキーの接続確認・保存・リセットまで実装されている
