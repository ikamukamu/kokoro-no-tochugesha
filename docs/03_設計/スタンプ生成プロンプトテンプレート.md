## 制作の分担（2026-10-27に決定）

- **枠・文字・切符はテンプレート**：外周の線路の円、切符風のタグ、二字熟語の文字は、AIに作ってもらった既存のスタンプ画像を使う
- **スタンプごとに作るのは、ペンギンと背景（添える絵）だけ**。ほしいもさんが、手作業で枠に重ねる
- ペンギンは、段階1（カラーの絵）を、形を変えずに、下記の決め事でピンク1色へ**機械的に変換**する（AIに描き直させない）
- ユーザーの言葉：「作ってもらった画像で良いす。枠、文字、切符に関してはテンプレなので、作ってもらうペンギンと背景だけ自分で手動で重ねれば良い気もするね。」
- 2026-11-09に見直し：背景は必須ではなく、任意の層にする（下の「背景の作り方」）

## ペンギンの1色変換の決め事

- 3段階：**塗り**（黒い部分＝頭・手・輪郭）／**斜線**（紺の部分＝帽子・制服。斜め45°、幅約5px）／**抜き**（白い部分＝顔・布団。透明）
- 頬の赤みは、塗りの点にする
- 帽子のバッジは、文字を消して、輪郭だけの丸にする。くちばしは塗らず、輪郭だけにする
  （ユーザーの言葉：「帽子のバッジ文字は消す。くちばしは塗らない。」）
- 色は `#f72572`、背景は透明。顔は1つ・目は閉じた線、とつながった体になっているかを、変換前に確認する

## 画像のフォーマット（全スタンプ共通）

| 縦横比・サイズ | 4:3を想定（当初は1024×768）。書き出しの実際の大きさと余白は、未確定（枠が中央になるよう切り出して使っている） |
| 外周 | 線路の円（かすれた質感）。全スタンプで同じ位置・同じ形 |
| 切符風タグ | 左側。No.・駅名（やまとことばのローマ字）・Neuro Railway を入れる。全スタンプで同じ位置・同じ形 |
| 二字熟語 | 上部に、太めの明朝体 |

## 制作の手順（2段階）

### 見本画像（毎回、添付する）

- `assets/images/penguin/common/penguin_front_01.png`（駅長の正面）
- `assets/images/penguin/icon/stationmaster_front_icon.png`（アイコン）
- 必要なポーズに近い既存画像があれば、それも添付する

### 段階1：形を決める（カラーでよい）

```
添付の駅長ペンギンを、デザインを一切変えずに使ってください（帽子・体型・顔を変えない）。
ポーズ：【ポーズ】
普通のカラーイラストでよいので、このペンギンだけを描いてください。背景は無地。
```

確認すること：帽子・体型・顔が駅長のままか。ポーズは合っているか。ずれていたら、スタンプにする前に、ここでやり直す。

### 段階2：スタンプにする

```
添付の絵（駅長ペンギン）の形は、一切変えないでください。これを、1色のスタンプ画像にしてください。
・色は #f72572 の1色だけ。背景は透明（塗りつぶさない）
・外周は、線路の円（かすれた質感）。左に切符風のタグ（【No.】/【駅名】/ Neuro Railway）
・上部の文字：「【二字熟語】」（太めの明朝体）
・日付は入れない
・背景（添える絵）は、描かない（あとで、別の手順で足す）
```

## 背景の作り方（2026-11-09に決定）

背景は、スタンプの必須の部品ではない。ペンギン・枠・文字・切符だけでも、スタンプは成り立つ。

### 考え方

- 背景を生成AIに単独で作らせると、枠やペンギンと画風が合わず、おもちゃ風になる。コードでの作画（朝日の弧、光線、銀河鉄道）も試したが、絵の力が足りなかった（ユーザー：「無理無理 レベルが違う」）
- そこで、**完成したスタンプ（背景なし）を、AIに見せて背景を足してもらう**。AIが画風を見て合わせられる
- ユーザーが示した手順：「・まず背景無しでそれ以外は完成しているスタンプを作る ・それをもとに元画像はいじらず、背景を足して完成してもらう（統一感がある画像が差し込まれる） ・良い感じのものができたらペンギン部分も塗り足した背景だけを作成してもらう」
- 返ってきた絵は、完成品としては使わない。**背景部分（月・星など）だけを取り出す**。枠・ペンギン・文字・切符は、こちらの原画のまま上に重ねる
- ユーザーの提案：「枠とセットでグループ化されたものを何パターンか用意しておく感じで、ペンギンを張り、文字と切符更新をすれば完成、みたいなの。」→ 背景はパターンとして用意し、スタンプごとに選ぶ

### 色

- ユーザーの言葉：「ビビッドピンクで目をかわいさとゴシック感を出しつつ、ゴールドできらびやかなアクセント」「ココロの途中下車がベースとして夜のプラットフォームで暗い背景だから、そこに押すスタンプとしてピンクとゴールドって良いよね」
- 背景だけ、ゴールド `#F5D77A`。明るさ3段階（`#E8C468`／`#F5D77A`／`#FFE49A`）を比べ、ユーザーが「Bでいこう」と決定
- 暗い画面に押す前提。ペンギンの白い部分は、透過のまま（暗い画面の色が見える）

### 世界観の参考（雰囲気のみ）

ユーザーが目指す背景のイメージ：「ゴシックレトロファンシーダークビビッドウォームがごちゃごちゃしないで表現されている」（アニメ『輪るピングドラム』の高倉家・ヒマリの部屋の場面）。
作品の場面やキャラクターは描かない。「幕（カーテン）で囲う」「中央を明るく、まわりを暗く（斜線のハッチングで表現）」「大きく読める形」「光る星だけが明るい」という作り方だけを借りる。今は、時間の面から、この方向の作り込みは、見送っている。

### 将来の余地

背景を別の層にしてあるので、星が、ゆっくり瞬くなどの動きを、あとから足せる。ユーザーの言葉：「背景だけ少し動くってのも良いけど（秋の葉っぱみたいに）そこまではやめた方が無難だもんね。」今回は、実装しない。

### 背景を足してもらう依頼文（夜空パターン。完成スタンプ（背景なし）を添付）

```
添付のスタンプ画像は、完成した状態で、元のデザインは変えたくありません。ペンギン、線路の円、文字「【二字熟語】」、切符は、形・位置・線の太さ・色を、そのまま、1ピクセルも変えずに残してください。
円の内側の背景に、夜空（三日月と、大小の星）を、描き足してください。
- ペンギンの後ろだけに描き、ペンギンの体には重ねないでください（ペンギンの内側は、白のまま）。
- 線の太さと、ピンクの1色という作りは、今のスタンプと同じにしてください。
- 子供向けのおもちゃ風にはせず、落ち着いた雰囲気にしてください。
- 月は、円の左上か右上の、ペンギンにかぶらない位置に置いてください。
- 市松模様（チェック柄）の背景は、描かないでください。
```

- 渡す画像は、枠が中央になるよう、正方形に切り出したもの（余白が大きいと、AIが余白に描くことがある）
- 取り出しは、生成画像から、ピンクの塊を数え、枠・切符・ペンギン・文字を除いて、残りの月・星だけを、枠の大きさに合わせて写す
- ユーザーの意見：丸い点の光は、表現があいまい。星は十字（4方向に尖る）のほうが好み（五角形はおもちゃ風）。今回は、夜空を、五角形の星のまま仮決めした

## PowerPointでの組み立て手順（No.003で確認、2026-11-05〜09）

- スライドは、ユーザー設定で、幅33.87cm × 高さ25.4cm（4:3）。最背面に、スライド全体の大きさの、透明な四角形（塗りの透明度99%、線なし）を置き、書き出す大きさをそろえる
- 重ねる順（下から）：背景 → 枠の円 → ペンギン → 二字熟語 → 切符
- 枠の円（PNG、幅 23.3cm、左 5.3cm、上 1.05cm）。背景も、同じ大きさ・位置に置く
- ペンギン（PNG）：幅 11.3cm、左 11.3cm、上 8.0cm を基準に、ポーズごとに調整する
- 二字熟語：游明朝 Demibold（ユーザーが選んだ）、色 `#F72572`。上の位置は、4.4cm 前後（文字を少し下げた）
- 切符：角丸の四角形に、白い枠線と白い文字（No.・駅名・Neuro Railway）。位置・角度は、スタンプごとに、少しずつ、ユーザーが調整してよい（No.003は、左の枠にかかる位置）
- 書き出し：全部を選択してグループ化し、右クリックの「図として保存」でPNG
- 次のスタンプ：スライドを複製して、二字熟語・切符の文字・ペンギン（図の変更）・背景を差し替える
- ペンギンの白（透過）の部分は、背景を足すと透けるため、背景は、ペンギンの後ろに置く要素を避けて作る（上の「背景の作り方」）。ペンギンの内側を、白で塗った版を、コードで作ることもできる

## 切符と駅名の決め方（2026-10-29に決定）

- 二字熟語を、上部に大きく置く（主役）
- 切符は「ただの装飾」。**やまとことばのローマ字**を、駅名として載せる（No.・ローマ字・Neuro Railway の3行）
- 駅名をやまとことばのローマ字にする理由：呼吸のあとの、癒しや満足感を後押しする場面で、文字数・文字の印象・意味の強さが
  かみ合う言葉にするため。学術用語（脳や神経の用語）は、強く硬いので、押印の画面では使わない。
  コレクション帳（[[ISS-056]]）の「駅の豆知識」に載せる案とする（効能を断定せず、公開前に内容を確認する）
- 経緯のユーザーの言葉：
  - 「このスタンプが呼吸の事後に押されるということを改めて考えると、癒しや満足感を後押しするスタンプとのズレ感あるなあ
    文字数、文字の印象の強さ、意味の強さ、なんかはかみ合わないのかな」
  - 「二文字・三文字をドーンと配置し、切符はただの装飾の役割としてローマ字でちょっと格好良く、そのまま駅名として機能させちゃっても良いのかもな」
  - 「あ、Bいいね！」（やまとことばのローマ字案）
  - 「他語句がローマ字だから、やっぱAKASAKAだね」（No.001は、RED SLOPEではなくAKASAKA）

### 制作の流れ

1. **セットを決める**：No.・二字熟語・駅名のローマ字・ポーズ・背景（任意）を、上の一覧に書く
2. **段階1のプロンプトを作る**：見本画像つき、ポーズの指定、顔は1つ・目は閉じた線、の指定
3. **段階1の絵を確認する**：顔の数・目の数・体のつながりを数える。帽子・体型・顔が駅長のままか
4. **1色へ変換する**：塗り・斜線・抜きの3段階で、機械的に変換する（形を変えない）
5. **背景を決める**（任意）：パターンから選ぶ（上の「背景の作り方」）。なしでもよい
6. **枠に重ねる**：枠・文字・切符のテンプレートに、ペンギン（と、あれば背景）を重ねる（ユーザーの手作業）。切符のNo.と駅名、上部の二字熟語を差し替える（上の「PowerPointでの組み立て手順」）
7. **登録する**：画像を`assets/`へ置き、アプリが読む一覧に追加する（実装時に決める）
